# MSJQA
## Microsoft Junior QA/Software Tester Professional Certificate

### Professional Certificate - 6 course series

The Junior QA / Software Tester Professional Certificate is an entry-level program designed to help you launch a career in software quality assurance. Software testing is a critical part of modern software development, creating opportunities for professionals who enjoy problem solving, attention to detail, and improving product quality. Targeted at career switchers and beginners, this program develops job-ready skills in software development life cycle (SDLC) methodologies, defect management, API validation, and troubleshooting.  You will gain hands-on experience with industry-standard tools, including Jira and Zephyr, Azure DevOps, Visual Studio Code, and Playwright. The curriculum guides you from testing principles to technical execution. Participants map testing activities to Agile and Scrum frameworks, executing smoke and regression tests. They then move to backend testing, writing SQL queries for data validation, and conducting load testing using Apache JMeter. The program covers Generative AI for intelligent test design and defect analysis. You will complete a career development course on resume optimization, GitHub portfolio creation, and interview preparation to help you showcase QA skills during the job search. Graduates are prepared for roles such as Junior QA Tester, Software Tester, QA Analyst, Quality Assurance Engineer, and Manual Tester. Some exercises may require paid tool tiers.
